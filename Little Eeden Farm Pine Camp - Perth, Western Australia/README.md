# Little Eeden Farm Pine Camp

Website for Little Eeden Farm Pine Camp, 429 Cook Road, Mooliabeenee WA.

Plain HTML/CSS/JS, no framework. Open `index.html` to view.

## Build

```
npm install
npm run build
```

Writes a minified, deploy-ready copy to `dist/`.

## Structure

- `index.html` — the page
- `assets/css/style.css`, `assets/js/main.js`
- `assets/img/` — web-ready photos and logo (cropped from `images/`)
- `images/` — original photos supplied by the client
